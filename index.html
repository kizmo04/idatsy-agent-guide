01 / THE NUMBERS

가장 중요한 구분 — $187.3M은 수익이 아니라 거래대금. 거래를 반복하면 자본 대비 누적 거래대금이 매우 커질 수 있다. 결승 PnL 역시 모의 대회 환경의 손익으로, 실계좌 수익과 다르다.

03 / DESIGN, NOT A LEAKED BLUEPRINT

에이전트 여러 개가

아래는 idatsy의 실제 내부 구조가 아니라 개인 트레이딩 시스템을 위한 설계안이다. 역할 분리, 판단 조정, 주문 실행을 독립시킨다.

참고: TradingView Indicator for AI Agents ↗. 시장 정보를 JSON으로 전달하는 접근이며, 수익이 검증된 전략이라는 의미는 아니다.

AI: 분석 및 계획 제안의견은 구조화된 데이터로만 제출, 직접 주문 권한 없음
→
Policy / Risk Gate포지션 한도, 비용, 승인 상태, 만료, 데이터 신선도 검증

가장 중요한 원칙 — AI가 “지금 팔아야 한다”고 말하는 것과 거래소에서 주문이 체결되는 것은 별개다. 분석, 승인, 검증, 실행을 분리해야 재현성과 안전성을 확보할 수 있다.
04 / A REAL DECISION PROBLEM

BTC 61.9K에서
왜 익절하지 못했을까?

예상 반등 후보 구간은 60K~62.2K. 가격은 61.9K까지 내려왔지만 추가 하락 기대 때문에 익절이 미뤄졌다. 무엇을 다르게 설계할 수 있을까?

BTC/USDT · 숏 포지션개념도 · 실제 차트 아님

핵심 문제는 저점을 못 맞힌 것이 아니라, 목표 구간에서 행동할 규칙을 미리 정하지 않은 것이다.

시나리오를 선택해 보기

기존 방식 · 판단 보류

61.9K 도달 후 60K까지 더 내릴 거라는 기대 때문에 청산을 미룸. 사전에 정한 반전 조건이 없어서 급반등 시 수익 일부를 반납.

AI가 해결해야 하는 일

  • 62.2K~60K가 실제 지지 구간인지 근거와 반대 근거 확인
  • 익절 구간과 구조 무효화 조건을 사전에 작성
  • 주문은 승인된 계획에 따라 실행하고 변경을 기록

이 예시는 익절 결과를 보장하지 않는다. 실제 비율·조건은 거래 기록으로 검증해야 한다.

05 / DOES IT MAKE MONEY?

에이전트가 똑똑해도
비용이 더 크면 실패다.

거래 비용을 직접 바꿔보자. 계정별 실제 수수료·페이백과 시장 상황을 반영해야 하며 아래 기본값은 예시다.

왕복 거래 비용 계산기

왕복 수수료10.00
왕복 슬리피지4.00
예상 총 비용 (USDT)14.00

양방향 체결 명목금액 동일 가정. 펀딩비·유동성 충격·AI/API 비용·마진 변동은 별도. 실제 체결 가격으로 재측정해야 한다.

AI 사용 전 반드시 비교할 3가지

A · 기존 수동 매매현재 행동을 기준선으로 측정
B · 단순 규칙분할 익절 + 추적 청산
C · AI 에이전트상황별 청산 계획 제안
C가 B를 이겨야 한다. 더 많은 에이전트가 더 나은 순기대값을 뜻하지 않는다. 같은 진입·시장 국면에서 수수료 차감 후 손익, MDD, 지연, 계획 준수율을 비교해야 한다.
06 / BUILD THE SMALL THING FIRST

50개부터 만들지 말고,
한 가지 문제부터 해결하자.

우선순위는 BTC 포지션의 익절 계획과 실행 안정성. 모델의 화려함보다 검증 가능한 개선이 먼저다.

PHASE 01

데이터와 복기

거래소 읽기 전용 API, TradingView 데이터, 매매 계획 이력을 수집. 수익 반납 사례의 기준선을 구축.

PHASE 02

분석 에이전트

추세·유동성·반전·비판 역할을 구현하되 주문 권한은 주지 않는다. 구조화된 근거와 반대 의견 저장.

PHASE 03

페이퍼 트레이딩

미래 데이터 누수 방지. 수수료·슬리피지·지연을 포함해 단순 규칙과 AI 분석을 동일 조건에서 비교.

PHASE 04

제한적 자동 청산

승인된 조건만 실행. 보호 주문·중복 방지·킬스위치·API 장애 대응을 갖춘 뒤 소규모 검증.

구현 후보: TypeScript + Node.js + Next.js + PostgreSQL + 거래소 WebSocket / TradingView Webhook. HFT 수준의 Rust 인프라는 초기 요구사항이 아니다.

07 / OPEN THE PRIMARY SOURCES

검증할 수 있는 링크들

원본 근거를 직접 열어볼 수 있도록 모았다. 영상 관련 설명은 자동자막 기준이며 실전 AI 전략 코드는 공개 확인되지 않았다.
